# Snip visual language

## Tokens

- **Background:** `#0b0b10`; surface `#14141b`; elevated surface `#1c1c25`
- **Text:** `#f7f5f2`; muted `#9b98a5`; subtle `#686572`
- **Accent:** `linear-gradient(110deg, #ff876d, #f45c9a 52%, #9b72ff)`
- **Font:** Inter, ui-sans-serif, system-ui, sans-serif
- **Type scale:** eyebrow 0.7rem, body 0.95rem, intro 1.1rem, heading `clamp(3rem, 8vw, 5.5rem)`
- **Spacing:** 8px base rhythm; sections use 64px gaps and 24px page gutters
- **Radii:** 14px controls, 24px cards, 999px hero input
- **Borders:** `1px solid #292832`; soft shadows with a warm accent glow
- **Glow:** fixed, full-viewport-width coral/pink/orange blur behind the hero; non-interactive

## Snip mapping

- Page header is the centered hero with a bold gradient headline and quiet subline.
- URL form is the pill-shaped chat-style input with the attached gradient action.
- Result and error notices are compact rounded status surfaces.
- Links table is the lower rounded surface card with subdued rows and accent links.
